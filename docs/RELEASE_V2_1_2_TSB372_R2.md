# TSB-372-R2 真实模型与真实素材验收

基线 `main@d699259352c42753f198a3514a0eed4e70516534`。产品版本 2.1.2。

| 问题 | 本轮整改 | 验证 |
| --- | --- | --- |
| 静帧缺失状态会被解释为已观测，多帧人工否决会被写成事实 | 显式状态与人工判定进入证据目录及同一校验器，人工确认的来源随证据输出 | 旧代码 13 项失败。覆盖历史与新读数、人工否决／不清楚／确认、未知状态 |
| 未绑定时序、质量不足和受限的视频事件可进入 Claim | 事件绑定实际派生片段及原片秒数，使用已有质量和证据种类，明确保留未校准置信度 | 对抗测试覆盖缺时序、超出片段、不确定限制与篡改引用 |
| 旧 Prompt 的结果无法证明当前提示词 | 用隔离库及不重试的真实文字请求，冻结同输入规则稿和模型稿，复用服务端回执校验和正式 A/B 路由 | 61/61 候选、11 镜头／60 秒、一次调用。新会话待真人评审 |
| 探测直连 HTTP 缺预算记账，单次结果缺多轮归因 | 现有探测工具支持既有账本，按实际序列化字节记账，单轮保留健康与时序信号 | 基线 CLI 预算回归红测。真实纯文字 200，合成视频 400 且服务端 `video=0` |
| 真素材有效子区间刚生成即被当成失效，播放器报 409 | 预览身份保存生成时的完整镜头范围，媒体读取同时校验完整范围与素材签名 | 用正式 API 复现子区间状态为 stale；回归覆盖可播放和父区间变更后拒绝 |

本轮只读打开正式素材与数据库。回执、盲评与派生片段位于隔离工作区。正式故事板、历史评价和原生视频能力记录保持原样。无需数据库迁移，未加入执行版本数据库持久化或最终渲染。正式验收尚待原生视频和真人评审解锁，验证结果见 [阶段验收](validation/tsb372-r2/README.md)。
