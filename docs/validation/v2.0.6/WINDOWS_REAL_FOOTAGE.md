## 一、验收流程（待执行）

1. 选取 8～10 段真实旅行视频：至少一段约 10 分钟、一段几十秒、横屏与竖屏、
   有音轨与静音；有 HEVC/4K 或 VFR 时一并纳入。先选小样本，不跑全部 200GB。
2. 对选取的原片记 **SHA-256 / 文件大小 / mtime**，记录写到独立验收目录，
   **不能写入原片目录**。
3. 创建项目并指定**独立输出工作区**（不与素材重叠）。
4. 通过正式 API/UI 依次执行：扫描 → 检测/抽帧 → AI 分析包 →
   有效与无效复核请求导入 → 二轮预览生成与 Range 播放 →
   人工评审/镜头调整 → 剪辑计划 → 粗剪播放。
5. **分别在代理与粗剪处理中执行取消**，并**立刻再次创建任务**，核对：
   - `cancelling` 期间新任务返回 **409**；旧任务真正结束后返回 **202**；
   - 记录三个时刻：取消响应时刻 / 进程退出时刻 / 清理完成时刻；
   - 子进程（含孙进程）经任务管理器确认退出；
   - 该任务 staging 目录无残留，**残留字节数**记录在案。
6. 复验原片 SHA-256 / 大小 / mtime 逐项不变；
   复验历史收藏、备注、用途、裁剪、剪辑计划引用仍在。
7. 保存可脱敏的截图、Job JSON 与播放器定位记录。
