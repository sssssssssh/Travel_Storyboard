# v2.1.1 Mac 真实素材验收记录

日期：2026-10-15。环境：macOS arm64 / Python 3.12.14 / 本机真实 FFmpeg、FFprobe。运行代码为 R2-C + 本批 TSB-319 路由接线修正；最终精确 HEAD、CI Run、7 个 Job 的计数另以最终 CI 存证为准。

本轮实际执行了真实服务和真实素材路径，但 **8～10 段、多类型矩阵及完整 UI 人工验收仍未完成**。结论：**代码级整改通过，发布门禁未完成**。

## 素材与隔离

用户提供目录内实际只有 6 段视频，4,759,917,235 bytes。全部为 MP4、HEVC、3840×2160 横屏、有音轨、bt709；时长 10.795～140.791 秒。H.264、MOV、竖屏、无音轨、HDR 均未测，不能把 8 个镜头说成 8 段视频。去 EXIF 不等于人脸/车牌脱敏；本轮在用户明确确认有外发权限后才发送真实素材帧。

每段先记录 SHA-256/mtime/大小，并以独立文件副本验收。复制现有 SQLite 和 282 个派生文件（51,858,349 bytes）到被 Git 忽略的隔离目录；保留 Asset/Segment ID 和精确区间，仅在验收副本调整源及工作区存储路径。正式 SQLite 和历史派生工作区不作为模型结果写入目标。现有 100 个检测镜头中选择跨 6 个素材的 8 个，未伪造检测边界或重映射 ID。

`MAC_FOOTAGE_MATRIX.json` 仅含别名/技术类型/哈希，不含真实文件名/原片路径。最终 `MAC_PRESERVATION.json` 证明 6 段原片及副本 SHA、原片 mtime/大小不变，282 个原历史文件字节不变，正式 SQLite 所有旧表旧列与迁移前一致。
