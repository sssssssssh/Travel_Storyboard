**类别覆盖（如实记录，不伪造）**：
- 主体动作 / 运动转场 / 静态风景这三类**无法从数据库元数据可靠区分**。

### 1.2 为什么 1、2 号需要缩短

`d8bd42e8`（22s）与 `4d24126f`（19s）超过 `DEFAULT_MAX_CLIP_SEC = 15.0`。
若执行真实调用，派生 clip 会被截断到 15 秒，**事件时间窗也随之改变**。
建议改选 #3–#6（7.6–10s），幅度更小、更省费用、也更接近默认上限。

## 4. 授权后才会执行的步骤

1. 在**隔离数据目录**复制项目元数据（不复制原片），创建合成项目；
2. 用项目自带 FFmpeg 派生静音 clip（放大到 720p 以内以满足 8MB 限制）；
3. 调用既有 `NativeVideoVisionProvider`，**验证实际协议为 `video_url` 原生视频**，
   不退化为抽帧；
4. 记录：Job 终态、HTTP attempt 次数、clip 字节数、是否使用代理、模型返回状态
   （**不含密钥**）；
5. 读取真实 `SegmentVideoObservation`，对照 `/video-observation`、
   `/director/candidates`、`/director/context`；
6. 核验 `video_native_valid` 从 0 → N，`segments_with_any_valid_reading` 按**去重**口径变化；
7. **请至少 1 段由人逐条观看**，确认事件描述、时间起止与实际画面大致一致；
   人工确认结论与模型自报 `confidence` **严格分开记录**；
8. 核验源文件 SHA-256 / size / mtime 不变（抽样）。
