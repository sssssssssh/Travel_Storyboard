## 数据契约

- 盲评阶段只返回统一的镜头、切片、时间轴及叙事结构投影，理由和节奏按角色与时长生成。两侧统一使用直接切换试剪。原始转场偏好和解释在提交后展示，因此提交前的「理由可信度」针对标准化理由和实际画面。
- 分组使用 `input_digest`、`input_version`、`brief_digest`、`theme_digest`、`target_duration_sec`、`candidate_limit`、`prompt_version` 与 `model_id`。简报其余条件也进入 `brief_digest`，比如叙事风格和方案数。缺历史字段时保留旧轮次并各自标记 `legacy_unknown`。无需改写历史数据。
- 模型 `PlanDraft 1.1` 由服务端生成可呈现的标题、理由、转场和节奏文本。事实键只在当前镜头的已过滤证据目录中解析。人工信息直接引用本地备注或用途。人工备注原文不外发。结构化验证拒绝跨镜头、失效、虚构引用和内容篡改。旧版 `1.0` 的模型文本及回执仍可读取，执行页将历史模型描述标为待复核。
- 剪辑输入的原始文本按方案与镜头分开保存，锁定镜头不可改区间或移除。非法或未提交时间输入阻止保存与导出。以当前可用区间为界，最短 0.05 秒，输入支持最多 9 位小数。所有执行输出使用同一份已提交的状态。
