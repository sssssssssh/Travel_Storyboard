三、"used == []" 的正确解读（任务书 §2.3）
------------------------------------------
used == [] 仅证明 provider.complete_video() 未被调用，**不能**单独证明
是哪一步失败。按 D1/D2 的代码位置，真实中断点在：
  derive_clip → run(expect_output) [此处已长路径安全] → probe_clip [D1 ∩]
  → note_derived(stat) [D2∩] → VideoPart(read_bytes) [D2∩] → complete_video
即 D1 与 D2 都位于 complete_video 之前，任一触发都表现为 used == []。
本轮通过**注入式确定性测试**分别证明 D1/D2，而不是靠猜。
