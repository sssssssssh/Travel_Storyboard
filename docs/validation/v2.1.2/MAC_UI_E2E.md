## 本轮修复的 UI 缺陷及红绿

1. 扫描结束只在 hasActive=true 时刷新，终态可能漏掉最终项目统计/素材列表；快任务首次轮询已经终态时会永久显示 0 素材并禁用检测。新增两个场景先 2 failed/6 passed，再修改终态刷新后 8 passed；反向恢复旧条件又 2 failed。只改刷新触发，不改后台互斥。
2. 视觉结果轮询依赖运行中状态，候选/多帧列表只在开始时刷新，终态没有最终刷新。新增语义/动态两个快任务先 2 failed/19 passed；在实际终态刷新四个相关查询后 21 passed；反向断开刷新又 2 failed。最终所有前端 48 passed，typecheck/lint/build 通过。

原始脱敏日志 c-project-*、c-vision-*；接线和反向恢复均完成。
